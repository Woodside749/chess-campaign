Credits

Chess Campaign is built on free and open-source software. Thank you to everyone who made it.

The chess engines

The bots think with these engines. They are free software under the GNU General Public License, version 3 (GPL-3.0), and their source code is available at the links below.

  • Stockfish, in the browser via stockfish.js (version 19) — source code
  • Fairy-Stockfish, for fairy chess and the other variants, via fairy-stockfish.wasm and ffish.js — source code

Chess Campaign's own code

Chess Campaign itself is free software under the same licence, GPL-3.0 (or any later version). You may read, change and share its code under that licence: github.com/Woodside749/chess-campaign.

Other building blocks

  • chess.js (BSD licence) — the chess rules
  • React and react-chessboard (MIT licence) — the screens and the board
  • Supabase (MIT licence) — accounts and saved progress

Puzzles

The puzzles in the Puzzle Trials come from the Lichess puzzle database, which Lichess shares freely with everyone (CC0).
